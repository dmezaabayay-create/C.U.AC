# C.U.AC
Captura el mundo real, un humano a la vez.

¿Alguna vez quisiste registrar a las personas únicas o curiosas que te cruzas en el día a día? CUAC es una aplicación que transforma el mundo real en un juego de colección donde puedes tomarle una foto a una persona para guardarla automáticamente en tu Intecodex, generando una ficha completa con sus características, nivel de rareza y fecha de avistamiento para que puedas completar tu colección.
